# Symmetrie-Werkstatt

Interaktive Kongruenzabbildungen für die Vorlesung „Lernen und Anwenden von Geometrie“ (GIMB, Universität Münster).

**App öffnen:** https://docschwob.github.io/symmetrie-werkstatt/

## Herausgeber

Dr. Simeon Schwob, GIMB – Institut für grundlegende und inklusive mathematische Bildung, Universität Münster

## Datenschutz

Die App erhebt keine Daten: Eingaben werden nicht an einen Server gesendet. Der Übungsstand wird nur im eigenen Browser gespeichert (localStorage) und lässt sich dort löschen. Die Seite wird über GitHub Pages bereitgestellt; GitHub verarbeitet dabei technisch notwendige Zugriffsdaten wie die IP-Adresse ([Datenschutzerklärung von GitHub](https://docs.github.com/de/site-policy/privacy-policies/github-general-privacy-statement)). Dienste Dritter sind nicht eingebunden.
